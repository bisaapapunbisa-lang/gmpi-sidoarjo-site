PANDUAN MENGAKTIFKAN PENDAFTARAN ANGGOTA ONLINE (± 5 menit)

APA YANG BERUBAH DI ZIP INI
- Formulir "Gabung Barisan" di situs AKTIF mengirim dan menyimpan data
  (sebelumnya hanya tampilan/prototipe).
- Foto KTP & pas foto tersimpan di penyimpanan privat. Yang bisa membuka:
  hanya Pemilik dan Petugas Registrasi (peran registrar). Pengunjung sama
  sekali tidak bisa membaca file-foto tersebut.
- Kotak centang persetujuan privasi di formulir (wajib sesuai undang-undang
  perlindungan data pribadi).
- NIK yang sama tidak bisa mendaftar dua kali.
- admin.js juga ikut diperbarui: hanya memperbaiki susunan tabel pada
  tab "Kehadiran" (fitur kemarin), tidak ada fungsi yang hilang.

LANGKAH 1 — Jalankan SQL (satu kali)
1. Buka https://supabase.com → login → proyek GMPI.
2. Kiri: "SQL Editor" → "+ New query".
3. Buka file: supabase/migrations/202610210016_aktivasi_pendaftaran.sql
   → Salin SEMUA isinya → tempel → klik "Run".
4. Muncul "Success" → selesai.

LANGKAH 2 — Unggah 3 berkas ke GitHub
1. Buka repo situs seperti biasa → "Add file" → "Upload files".
2. Seret TIGA berkas ini: index.html, script.js, admin.js
   (ketiganya otomatis menggantikan versi lama — memang begitu tujuannya).
3. Klik "Commit changes" → tunggu ±1 menit.

LANGKAH 3 — Coba dengan data asli pengurus (sekaligus cek sistem)
1. Buka: https://www.gmpisidoarjo.com/#gabung
2. Isi formulir dengan data ASLI salah satu pengurus (foto KTP & pas foto
   dari HP), centang dua kotak persetujuan, lalu Kirim pendaftaran.
3. Harus muncul tulisan "PENDAFTARAN TERKIRIM". Kalau muncul = sistem jalan.
4. Buka Admin → masuk (pakai akun Pemilik) → tab "Pendaftaran anggota" →
   data pengurus tadi terlihat, foto KTP & pas foto bisa dibuka.
5. Kalau semua cocok: bagikan poster + teks wa-validasi.txt ke grup
   anggota. Orang-orang tinggal klik tautannya.

KALAU HASIL UJI INGIN DIHAPUS
- Cara mudah: di tab "Pendaftaran anggota", ubah status data itu menjadi
  "ditolak" — maka NIK tersebut bebas didaftarkan lagi.
- Menghapus total bisa lewat Supabase SQL Editor bila perlu.

CATATAN
- Data NIK & foto tidak pernah tampil publik, tidak muncul di kartu anggota,
  dan tidak dibagikan ke peran lain. Hanya Pemilik dan Petugas Registrasi.
- Jika formulir pendaftaran ramai tidak stabil, mater undangan tetap tersimpan
  di folder undangan/ (bisa dibagikan kapan saja, tidak kedaluwarsa).
