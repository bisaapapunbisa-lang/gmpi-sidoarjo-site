TANDA TANGAN KETUA OTOMATIS DI BELAKANG SEMUA KARTU (2 berkas: member-card.js + admin.js)

CARA PASANG (sekaliseumur situs):
1. Unggah 2 berkas ini ke GitHub (timpa) → Commit changes → tunggu ±1 menit.
2. Login admin (Pemilik) → tab Pendaftaran anggota → Kartu anggota →
   buka "Pengaturan sisi belakang (penanda tangan)".
3. Di bagian "Tanda tangan Ketua — bawaan pusat (khusus Pemilik)":
   pilih file PNG/WebP tanda tangan (LATAR TRANSPARAN, maks 2 MB) →
   klik "Unggah sebagai tanda tangan bawaan semua kartu".
4. Selesai. Semua kartu yang diunduh setelahnya (depan+belakang) otomatis
   bertanda tangan di atas nama penanda tangan — berlaku di HP/laptop mana pun.

CATATAN:
- Kartu contoh di beranda TIDAK menampilkan tanda tangan (tetap bersih).
- Tanda tangan lokal per perangkat (kolom lama) tetap bisa dipakai dan
  didahulukan bila diisi.
- Kalau file tanda tangan berlatar putih (bukan transparan), hasilnya akan
  tampak kotak putih — bersihkan dulu jadi transparan, atau minta dibersihkan.
